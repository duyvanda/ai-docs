  2. **Tự động quy đổi ngày đầu và cuối tháng**:

     - `form_name`: Tên biểu mẫu.
     - `created_at`: Thời gian tạo hồ sơ ký số.
     - `updated_at`: Thời gian cập nhật trạng thái mới nhất.
     - `created_code`: Mã nhân viên lập biểu mẫu.
     - `created_name`: Tên nhân viên lập biểu mẫu.
     - `current_step_status`: Trạng thái bước duyệt/ký hiện tại (`pending`, `approved`...).

## 2. Chi tiết Stored Function PostgreSQL (`get_form_claim_chi_phi_forward_data_internal_sign`)

Function được viết bằng `plpgsql`, tuân thủ chuẩn `write_get_function.md`, không chặn validation bắt buộc và tái sử dụng helper `public.get_python_eo_data` sẵn có trên database:

```sql
-- FUNCTION: public.get_form_claim_chi_phi_forward_data_internal_sign
-- Language: plpgsql
-- Arguments: url_param jsonb

CREATE OR REPLACE FUNCTION public.get_form_claim_chi_phi_forward_data_internal_sign(url_param jsonb)
 RETURNS jsonb
 LANGUAGE plpgsql
AS $function$
/* 
Function: get_form_claim_chi_phi_forward_data_internal_sign
Mục đích: Lấy dữ liệu trình ký nội bộ từ eOffice theo kỳ chi phí và mã nhân viên.
Tự động chuyển kỳ chi phí thành ngày đầu và ngày cuối tháng để gửi API sang eOffice.
Không chặn validation bắt buộc mã nhân viên hay kỳ chi phí.
*/
DECLARE
    p_manv text := COALESCE(url_param->>'manv', '');
    p_ky_chi_phi text := COALESCE(url_param->>'ky_chi_phi', '');
    v_date date;
    v_date_start text;
    v_date_end text;
    v_params jsonb;
    v_raw_response jsonb;
BEGIN
    /* 1. Tự động quy đổi kỳ chi phí sang ngày đầu tháng (v_date_start) và cuối tháng (v_date_end).
          Nếu không truyền thì mặc định lấy tháng hiện tại. */
    IF length(p_ky_chi_phi) = 7 THEN
        v_date := (p_ky_chi_phi || '-01')::date;
    ELSIF length(p_ky_chi_phi) >= 10 THEN
        v_date := (SUBSTRING(p_ky_chi_phi FROM 1 FOR 10))::date;
    ELSE
        v_date := CURRENT_DATE;
    END IF;

    v_date_start := TO_CHAR(date_trunc('month', v_date), 'YYYY-MM-DD');
    v_date_end := TO_CHAR((date_trunc('month', v_date) + interval '1 month - 1 day')::date, 'YYYY-MM-DD');

    /* 2. Build params cho eOffice API */
    v_params := jsonb_build_object(
        'date_start', v_date_start,
        'date_end', v_date_end,
        'limit', 1000
    );

    IF p_manv <> '' THEN
        v_params := v_params || jsonb_build_object('user_code', p_manv);
    END IF;

    /* 3. Gọi API eOffice data-internal-sign qua helper get_python_eo_data */
    v_raw_response := public.get_python_eo_data(
        jsonb_build_object(
            'url', 'https://eoffice.meraplion.com/admincp/api/api/raw/data-internal-sign',
            'params', v_params
        )
    );

    /* 4. Kiểm tra phản hồi từ API */
    IF v_raw_response->>'status' = 'error' THEN
        RETURN jsonb_build_object(
            'status', 'fail',
            'error_message', COALESCE(v_raw_response->>'message', 'Lỗi khi gọi eOffice API')
        );
    END IF;

    /* 5. Trích xuất danh sách và chuẩn hóa format JSON trả về theo write_get_function.md */
    RETURN (
        WITH rows_data AS (
            SELECT
                elem->>'form_code' AS form_code,
                elem->>'form_name' AS form_name,
                elem->>'created_at' AS created_at,
                elem->>'updated_at' AS updated_at,
                elem->>'created_code' AS created_code,
                elem->>'created_name' AS created_name,
                elem->>'current_step_status' AS current_step_status,
                elem->>'attachment_name' AS attachment_name,
                elem->>'attachment_url' AS attachment_url
            FROM jsonb_array_elements(
                CASE 
                    WHEN jsonb_typeof(v_raw_response->'data') = 'array' THEN v_raw_response->'data'
                    ELSE '[]'::jsonb
                END
            ) AS elem
            WHERE (p_manv = '' OR elem->>'user_code' = p_manv OR elem->>'created_code' = p_manv)
            ORDER BY elem->>'created_at' DESC, elem->>'id_form' DESC
        )
        SELECT jsonb_build_object(
            'status', 'ok',
            'rows', (SELECT COUNT(*) FROM rows_data),
            'data', COALESCE((SELECT jsonb_agg(f) FROM rows_data f), '[]'::jsonb)
        )
    );

EXCEPTION
    WHEN OTHERS THEN
        RETURN jsonb_build_object(
            'status', 'fail',
            'error_message', SQLERRM
        );
END;
$function$;
```

## 4. Bổ sung Function `post_python_eo_data`

Dựa trên cấu trúc của [get_python_eo_data.sql](file:///D:/postgres/functions/get_python_eo_data.sql), đã tạo hàm `post_python_eo_data` chuyên dụng để thực hiện HTTP POST request sang eOffice API:
- **Files lưu trữ**:
  - [functions/post_python_eo_data.sql](file:///D:/postgres/functions/post_python_eo_data.sql)
  - [public/functions/post_python_eo_data.sql](file:///D:/postgres/public/functions/post_python_eo_data.sql)
- **Cơ chế hoạt động**:
  - Nhận `payload jsonb` chứa `url`, `params` (nếu có), và dữ liệu gửi POST **chỉ nhận duy nhất qua key `'data'`**. Nếu thiếu key `'data'` hàm sẽ trả về thông báo lỗi `"Missing 'data' parameter in payload"`.
  - Sử dụng chung bộ token & header chuẩn của hệ thống eOffice. Cho phép mở rộng override header nếu cần.
  - Hỗ trợ timeout 15s và tự động xử lý parsing JSON hoặc fallback text phản hồi.
